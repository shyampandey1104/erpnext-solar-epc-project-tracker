# ☀️ ERPNext Solar EPC Project Tracker & PV Sizing Engine

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/ERPNext-Solar%20EPC-blue.svg)](https://erpnext.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A specialized **Solar EPC (Engineering, Procurement, Construction) Project Management Engine** for **ERPNext**. Features rooftop PV capacity sizing, solar irradiation generation yield (kWh), annual electricity savings calculation, and DISCOM net-metering milestone billing.

---

## ⚡ Highlights
- 📐 **PV Sizing Algorithm**: Evaluates rooftop shadow-free area vs sanctioned grid load.
- ⚡ **Generation Forecasting**: Annual kWh projections based on regional solar irradiance.
- 💵 **Financial ROI**: Payback period and commercial tariff offset calculations.
- 🧪 **Pytest Coverage**: Unit tests included.
